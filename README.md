# ⚡ Electrical Engineering Software Suite

## 📖 About

Welcome to the **Electrical Engineering Software Suite**.

This repository contains a collection of Electrical Engineering software tools and calculators developed using GNU Octave, a MATLAB-compatible numerical computing environment.

The objective of this repository is to combine Electrical Engineering principles with software development by creating practical applications that automate engineering calculations and reinforce theoretical concepts.
